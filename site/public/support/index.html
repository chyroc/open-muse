Open Muse Privacy Support 中文

Support

Email support@getopenmuse.com. In the app, Settings > Report a problem (or shaking your iPhone) prepares a report you can send by email or any other app; in TestFlight you can also send feedback with a screenshot.

Getting started

  1. Install Open Muse from TestFlight and open it.
  2. Register or sign in with an email address and password. No email confirmation is needed, and there is no password reset in the app, so keep the password.
  3. Connect a Volcano Ark API key with access to Managed Agents in Settings > Account and workspace. If you were given an account with a key already connected, skip this step.
  4. Start chatting. The first conversation sets up your assistant, its cloud environment, and its memory.

Common questions

Does it cost anything? The app is free. Model and cloud usage is billed to the Volcano Engine account that owns the API key.

Why can't the assistant read my Health data? Allow access when iOS asks, or turn it on in iOS Settings > Health > Data Access & Devices > Open Muse.

How do I delete my data? See the privacy policy.

支持

发邮件到 support@getopenmuse.com。在 App 里，「设置 > 报告问题」（或摇一摇 iPhone）会生成一份报告，你可以用邮件或其他 App 发送；也可以在 TestFlight 里附截图发送反馈。

开始使用

  1. 从 TestFlight 安装并打开 Open Muse。
  2. 用邮箱和密码注册或登录。不需要邮箱验证；App 里没有找回密码，请记好密码。
  3. 在「设置 > 账号与工作区」连接一个能使用 Managed Agents 的火山方舟 API Key。如果你拿到的账号已经连好了 Key，跳过这一步。
  4. 开始聊天。第一次对话会准备好你的助手、云端环境和记忆。

常见问题

要付费吗？App 免费。模型和云端用量计入 API Key 所属的火山引擎账号。

助手为什么读不到我的健康数据？在 iOS 询问时允许访问，或在 iOS「设置 > 健康 > 数据访问与设备 > Open Muse」里打开。

怎么删除我的数据？见隐私政策。
