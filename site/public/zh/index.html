Open Muse 功能 开始使用 English

会记事、会跟进、能动手的个人 AI 助手

它在你的 iPhone 或 Android 手机上，在你的 Mac 上，也在一台云端电脑上——你关掉 App，它还在继续干活。

加入 iPhone 测试版 下载 Android 版 GitHub 上的源码

免费使用，源码在 GitHub 上。需要一把能使用 Managed Agents 的火山方舟 API Key。

它能做什么

同一个助手，所有设备。对话、记忆、目标和提醒都跟着你的 Open Muse 账号走。

按需读懂你的身体

问一句「这周睡得怎么样？」，它会当场读取 iPhone 上的 Apple 健康或 Android 上的 Health Connect：步数、运动、睡眠、心率、体重。读不到的数字，它绝不编造。

亲手操作你的 Mac

经你允许后，它可以查看屏幕，打开 App 和文件，点击、输入、滚动——任何 App 都行。除非你提前允许，每个动作都会先等你批准。

飞书，一句话办完

登录一次，之后直接用大白话：开会前给我一页简报、把今天的群聊整理成任务、把昨天的会议纪要写成文档。

一直在干活的云端电脑

每个工作区都有自己的沙箱：网页搜索、真正的浏览器、终端和文件。把任务交给它，关掉 App，回来时结果已经在那里。

记得住，会跟进

把重要的事记在你能查看和编辑的记忆里，把目标拆成计划并定期跟进，单次、每天、每周或每月提醒你。

只属于你的动态和点子

按你选的主题每天更新，每条都附来源；再根据你的目标和近期对话，准备好现成的任务。

值得信任

先问你

操作 Mac 或读取健康数据都要等你同意，除非你提前选择允许；日历和定位每次都会询问。

不假装回答

没有可用连接时，应用会直接说明，从不生成模拟回复。

你的 Key，你的工作区

应用用你自己的 API Key 直接调用火山方舟，Key 为你的账号加密保存。共用同一个 Key 的不同账号，工作区和记忆依然相互隔离。

记忆看得见

助手的名字、人格和记住的事实都是普通文档，你可以打开、修改或清空。

开始使用

iPhone

通过 TestFlight 加入公开测试，用邮箱和密码注册，再在设置里连接你的火山方舟 API Key。

Android

下载安装包（版本 {{android.version}}，{{android.size}}），打开即可安装；第一次安装时 Android 会请你允许浏览器安装应用。需要 Android 9 及以上，Health Connect 需要 Android 14 及以上。安装包会从离你最近的服务器下载，你也可以手动选择中国大陆或海外线路。

SHA-256 {{android.sha256}}

Mac 和网页版

用 GitHub 上的源码自行构建，步骤见开发文档（英文）。

费用

应用免费。模型和云端用量计入你的 API Key 所属的火山引擎账号。
