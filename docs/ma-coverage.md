# Managed Agents 接入范围

应用的接口目录位于 `shared/ma-contract.json` 和 `shared/ma.ts`。BFF 只允许已注册操作，不接受客户端传入任意上游 URL 或路径。

| 资源       | 数量 | 范围                                             |
| ---------- | ---: | ------------------------------------------------ |
| 智能体     |    6 | 创建、列表、查看、更新、删除、版本历史           |
| 运行环境   |    5 | 创建、列表、查看、更新、删除                     |
| 会话与事件 |   11 | 会话管理、环境筛选、资源挂载、消息、历史和事件流 |
| 记忆       |   12 | 记忆库、创建人筛选、记忆管理、批量写入           |
| 连接与凭据 |   13 | Vault、凭据管理与校验、OAuth 提供方和流程        |
| 技能       |    2 | ZIP 上传、按 ID 查询                             |
| 文件       |    3 | 上传、元信息和下载链接、删除                     |

合计 52 项。大多数操作通过 API Key 调用数据面；部分控制面操作需要 SSO 提供 STS。重复的控制面与数据面入口不重复展示。

## 使用方式

日常对话自动管理 Agent 与 Environment。只有高级工作台需要编辑路径参数、查询参数或 JSON 请求体。写操作需要确认，Agent 更新需要版本，删除需要核对目标 ID。

会话可挂载文件和 Vault；工具、MCP、技能及多 Agent 配置由上游执行。文件与技能上传上限为 10 MB；技能包应包含 `SKILL.md`。应用不在本机执行上传的技能内容。

MCP OAuth 需要在外部服务完成授权。文件下载返回上游生成的链接，BFF 不拉取用户提供的任意下载 URL；临时下载链接应按敏感链接保管。

## 边界

- 「已接入」表示适配代码与入口存在，不表示所有账号和环境均有权限，也不表示全部操作已经实账号验收。
- 不提供运维或管理接口；未注册的操作返回错误。
- 当前不提供技能列表、更新、删除，以及记忆版本历史入口。
- 可管理 `self_hosted` 配置，但应用本身不提供对应运行 Worker。
- 实时流位于任务详情，不由高级 JSON 编辑器承载。
- 默认云环境可访问公网；其他工具仍按权限策略要求确认。

接口字段的类型描述仅用于表单提示，不替代上游完整校验。更新目录前，应核对[火山方舟文档](https://www.volcengine.com/docs/82379)、权限和操作副作用，添加相应回归测试；运行时不会自动开放新路由。
